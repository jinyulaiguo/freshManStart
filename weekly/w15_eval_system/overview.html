Agent 评测体系 (Eval) 与 CI/CD 质量门禁

为 W14 AI 研究助手构建 Golden Dataset、多维度量化评测、回归 Diff 报告与 GitHub Actions 自动拦截流水线

里程碑三：LangGraph + Planning + Context Engineering + Eval = 具备完整质量保障体系的 Agent 系统。 W15 结束后即具备投简历的核心作品集能力（ReAct · RAG · LangGraph · Planning · Eval）。

Agent 迭代核心痛点与 Eval 体系对策

无评测体系时的工程灾难

  • Prompt 改动盲飞：改一句 System Prompt，20 个功能静默退化，无人知晓。
  • 工具调用幻觉：Agent 选错工具或参数漏传，自由文本看起来"专业"实则全错。
  • RAG 幻觉不可见：回复通顺流畅，但数据完全脱离检索 Context 编造。
  • 回归不可追溯：版本迭代后只知道"变差了"，无法定位具体退化 Test Case。
  • CI 无质量门禁：PR 合入主干后才发现 Agent 质量断崖式下跌。

Eval Pipeline 架构解法

  • Golden Dataset (Day 99)：50 条版本化 JSONL 测试集，覆盖边界 Case 与注入攻击。
  • G-Eval Judge (Day 100)：Rubric + CoT 多次采样，量化主观指标收敛度。
  • Tool F1 (Day 101)：Precision / Recall / F1 确定性统计工具调用准确率。
  • Faithfulness / Relevance (Day 102)：LLM Judge 探针检测幻觉与偏题。
  • CI/CD Gate (Day 103)：GitHub Actions 阈值拦截，指标降级阻断 PR 合入。
  • Regression Diff (Day 104)：EvalReporter 输出 Markdown 差异报告与 Case 级定位。

本周 7 天核心能力建设链路 (Day 99 → Day 105)

Day 99

Golden Dataset 构建与合成数据生成

定义 GoldenCase Pydantic Schema，从 W14 RAG 语料 + 注入样本合成 50 条 JSONL。实现 SyntheticGenerator 少样本种子提示词批量生成 + 人工校验流程。

交付物：golden/synthetic_generator_impl.py · golden_dataset_v1.jsonl
Day 100

G-Eval LLM-as-Judge 评测指标数学设计

编写 Rubric + CoT 评估 Prompt 模板，多次独立采样取加权均值，验证重测标准差 σ < 0.2 的收敛性。

交付物：evaluators/g_eval_judge_impl.py
Day 101

工具调用 Precision / Recall / F1 评估

实现 ToolExecutionEvaluator，比对 EvalTrace 与 expected_tools，终端表格输出 P/R/F1 及参数误差率。

交付物：evaluators/tool_execution_impl.py
Day 102

Faithfulness 与 Relevance 探针打分

两个独立 LLM Judge 探针：Faithfulness 检测 Context 外幻觉，Relevance 检测答非所问。假回复样本必须打出极低分。

交付物：evaluators/faithfulness_impl.py · evaluators/relevance_impl.py
Day 103

GitHub Actions CI/CD 评测流水线

编写 .github/workflows/eval.yml，指标低于阈值时返回非 0 exit code 拦截 PR。本地 Mock 验证拦截逻辑。

交付物：.github/workflows/eval.yml
Day 104

回归测试与 EvalReporter 差异报告

EvalReporter 比对两次 eval_result.json，输出 Markdown Δ 指标报告 + 降级 Test Case ID 清单。

交付物：reporter/eval_reporter_impl.py
Day 105

综合实战：AI 研究助手 QA 自动化评测流水线

拼装 run_eval.py + 全 Evaluator 链 + EvalReporter + CI Gate + Eval Dashboard。挂载 W14 Research Agent 完成端到端评测。

交付物：day105/ 完整工程项目 · README.md · start.sh · Dashboard
